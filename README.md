# Quién Puede

Plataforma chilena para conectar personas que necesitan resolver una tarea con empresas y prestadores de servicios cercanos.

## Estado

Prototipo funcional en desarrollo. Incluye búsqueda por servicio y ubicación, perfiles de prestadores, paneles para personas y empresas, oportunidades B2B, mensajería demostrativa y un portafolio de fotos y reels.

## Ejecutar localmente

La aplicación actual es estática. Puedes abrir `dist/index.html` o servir la carpeta `dist` con un servidor local.

```bash
python3 -m http.server 8080 --directory dist
```

Luego abre `http://localhost:8080`.

## Seguridad

Las credenciales de servicios externos, claves de Bunny Stream y variables privadas no se guardan en este repositorio.
